Evaluation Metrics

Accuracy

Percentage of test samples classified correctly.

Precision

Measures how many predictions assigned to a class were correct.

Recall

Measures how effectively the model identifies samples belonging to a class.

Weighted F1

Harmonic mean of precision and recall, weighted according to class support.

Macro F1

Average F1 score across classes, giving each class equal weight.

Test Set

Evaluation is performed using the held-out portion of the dataset.
